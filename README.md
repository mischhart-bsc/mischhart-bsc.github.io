# mischhart-bsc.github.io

Only here so the Judo Trainer Android app opens without a browser bar:
`.well-known/assetlinks.json` proves the app (io.github.mischhartbsc.judotrainer) belongs to this domain.
`.nojekyll` makes GitHub Pages publish the `.well-known` folder. `index.html` forwards to the site.
If the app's signing key ever changes, put the new SHA-256 fingerprint into assetlinks.json.
